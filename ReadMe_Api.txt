- Cocktail Generator – Random & Search App
This project is a cocktail generator built with Express.js and EJS, 
using TheCocktailDB API to fetch random drinks or search for drinks by name. 
Users can also view instructions and ingredients, with a fully styled responsive UI.

OVERVIEW 

- The challenge
  Users should be able to:
    - Generate a random cocktail
    - Search for a cocktail by name
    - See a list of ingredients and instructions
    - Experience a fully responsive design, optimized for desktop and mobile
    - Enjoy a smooth and styled UI with fallback content

- Links
    - GitHub: https://github.com/Argoneo/cocktail-generator
    - API reference: https://www.thecocktaildb.com/api.php
    - repository: https://cocktailmaker-mb1i.onrender.com

- My process
  - Built with
    - Node.js + Express
    - EJS templating
    - Axios (for API calls)
    - TheCocktailDB API
    - Vanilla CSS (custom responsive design)
    - Mobile-first layout
    - Custom scrollbars and button effects
    - Grid + Flexbox layout

- What I learned
    - How to use external APIs with Axios in a server-side environment
    - How to pass dynamic data into EJS templates
    - How to structure fallback content for missing data
    - How to design responsive layouts with pure CSS
    - How to manage conditional rendering in EJS based on API results
